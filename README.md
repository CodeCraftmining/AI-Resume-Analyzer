# AI Resume Analyzer 🚀

An AI-powered Resume Analyzer built using Flask and Python that analyzes resumes against job descriptions and provides ATS-based match scores, missing skills, and AI-generated suggestions.

---

## 🌐 Live Demo

👉 https://ai-resume-analyzer-7st5.onrender.com

---

## ✨ Features

- Upload Resume PDF
- Extract Resume Text
- ATS Match Score Calculation
- Missing Skills Detection
- Skills Visualization Chart
- AI Resume Suggestions
- Beautiful Modern UI
- Responsive Design
- Resume Skill Analysis
